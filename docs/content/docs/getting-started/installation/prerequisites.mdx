## Node.js

I manage different node instances on my system using [mise](https://mise.jdx.dev). However, you can install node the traditional way or other environment managers, such as nvm.

```bash
mise install node@20.20.2
```

## PostgreSQL

PostgreSQL is used as the database for Lumexia via [PrismaORM](https://www.prisma.io/orm).

- This app was developed with PostgreSQL 15.

## S3

An S3-compatible object store is required. Lumexia uses [RustFS](https://rustfs.com).

Point the `S3_END_POINT`, `S3_PORT`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, and `S3_BUCKET_NAME` environment variables at your RustFS instance. Any other S3-compatible backend should also work since the application uses the AWS SDK v3 with path-style addressing.

This section focuses on how to get Lumexia working.

## Prerequisites

This project is still in active development, so there are a number of prerequisites. The roadmap includes automatic setup using docker-compose. For now, please take a look at the [prerequisites](/docs/getting-started/installation).

## Methods

Unforuntantely, prebuilt packages are still a work in progress. Currently, Lumexia can be installed via the following methods:

- [docker](/docs/getting-started/installation/docker)
- [manually building from source](/docs/getting-started/installation/manual)

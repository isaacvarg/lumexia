## Niimbot B1

This is the label printer that is hardcoded to work with research and development samples. Future work should include wider coverage.

This label printer is realtively inexpensive and the [niimbluelib package](https://github.com/MultiMote/niimbluelib) has enabled usage as a bluetooth printer directly with Lumexia.

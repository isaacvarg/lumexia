title: Usage 
description: Running Lumexia on a tablet on the warehouse floor, and what to pair with it.
---

Lumexia runs in the browser, so it runs on a tablet exactly like it runs on a
computer. There is nothing to install and no separate app — open the site in the
tablet's browser and sign in. This makes a tablet a convenient way to carry Lumexia
onto the warehouse floor.

## What to expect

The interface is **responsive**: the same UI adapts to the tablet's screen. Actions
meant for the floor are surfaced as large, tap-friendly panels, so common tasks like
[inventory audits](/docs/inventory/audits) are comfortable to run standing up with a
tablet in hand.

There is **no dedicated tablet or kiosk mode** yet: it's the standard Lumexia web app,
sized for the screen you open it on.

## Pairing peripherals

A tablet is most useful on the floor when paired with the hardware the workflows
expect:

- A **Bluetooth barcode/QR scanner** in keyboard-wedge mode lets you scan lots and
  samples directly into the tablet — see [Scanners](/docs/hardware/scanners).
- Features that use **Web Bluetooth**, such as [Niimbot label
  printing](/docs/hardware/printers), require a Chromium-based browser (Chrome or
  Edge) on the tablet.

<Callout>
  Lumexia is an online app: it needs a live connection to the server. There is no
  native tablet app and no offline mode, so keep the tablet on Wi-Fi while you work.
</Callout>

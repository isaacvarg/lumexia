---
title: Scales
description: How weights get into Lumexia — entered by hand, not read from a balance.
---

Lumexia works with weights throughout — inventory amounts, transactions, and
production quantities are all measured values. But it does **not** connect to a scale
or balance. You read the value off your device and **type it in**.

## ESP8266 Future Work

There has been some success integrating Lumexia using ESP8266 microcontroller running a small server to send serial data to Lumexia from a "dumb" balance/scale. However, this work is very early and not ready for production. 

**Some capabilities on the wishlist include:**
- automatic registering of measurement in warehouse staging and lab analytical balances. 
- safe guards during staging
- container database registry to allow automatically calculation of gross/net content in warehouse containers
